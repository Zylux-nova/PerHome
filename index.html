系统折腾

能点鼠标就不敲命令，GUI 优先

Windows 日常维护

  • 装软件：Microsoft Store + Winget，少碰第三方全家桶
  • 清垃圾：设置 → 系统 → 存储感知，一键自动清理（纯 GUI）
  • 启动项：Ctrl+Shift+Esc 任务管理器 → 启动应用，禁用不用的
  • 驱动：Windows 更新 + 厂商官网，别用驱动精灵

Linux Mint 上手

  • 软件源：系统设置 → 软件源 → 选国内镜像，全 GUI 换源
  • 显卡驱动：打开"驱动管理器"，选 recommended 直接装
  • 打印机：设置 → 打印机 → 添加，输网络打印机 IP 即可
  • 装软件：用"软件管理器"（图形化应用商店），C++/Python 环境图形化装

Android 刷机（KernelSU / Magisk / LineageOS）

高风险 · 谨慎操作
  • ① 解锁 Bootloader：品牌官网申请解锁（会清空数据，先备份）
  • ② 进 fastboot / 9008 模式，刷入 TWRP Recovery 或直接 fastboot 刷入 LineageOS
  • ③ Root 方案二选一：KernelSU（内核级）或 Magisk（模块级），都靠 App 图形化管理模块
  • ④ 模块别贪多：装一个测一个，出问题进 Recovery 删模块即可
  • 提醒：刷机有变砖风险，先查自己机型的版块教程再动手；9008 模式是救砖的最后通道

摄影工作流

D750 · NTC/NCP · PS · 九宫格

NTC / NCP 曲线（直出调色）

  • 尼康官网下载 Picture Control Utility 2（GUI 软件）
  • 用曲线编辑器调 S 形对比度、饱和度（也可导入社区成熟曲线）
  • 写入相机存储卡 → 机身直出 JPG 就有味道
  • 同时应用到尼康工坊 NX Studio，RAW 后期统一观感

PS 修图标准流程

  • RAW 转档（ACR）：曝光、白平衡、高光阴影
  • 局部调整：蒙版、渐变、径向滤镜（压天空提地面）
  • 调色：HSL 精准调色 + 曲线 + 分离色调
  • 收尾：锐化 + 降噪 + 统一导出

九宫格拼图（朋友圈晒图）

  • PS 里用"切片工具"切 3×3，或用参考线手动分 9 格
  • 每格单独导出 PNG（注意留 1-2px 白边防缝）
  • 按 1-9 顺序发朋友圈，形成完整九宫格大图
  • 手机端懒人方案：九宫格拼图 App，选图自动切（GUI）

Python 照片批量重命名 
# 内蒙古之旅回来，把 DSC_xxxx.JPG 按日期批量重命名
import os

folder = "D:/Photos/InnerMongolia"   # 改成你的照片目录
files = [f for f in os.listdir(folder) if f.endswith(".JPG")]

for i, name in enumerate(sorted(files), 1):
    new_name = f"2026-10-23_{i:03d}.JPG"
    os.rename(os.path.join(folder, name), os.path.join(folder, new_name))

print(f"完成：{len(files)} 张照片已重命名")

简单食谱

快手菜，别翻车

脆炸薯条

  1. 速冻薯条无需解冻，油温 170°C 炸 3 分钟捞起
  2. 升温到 190°C 复炸 1 分钟，逼出油、更脆
  3. 撒盐和黑胡椒，配番茄酱开吃

温泉蛋拌饭

  1. 蛋放 60°C 水保温 20 分钟（或开水焖 12 分钟）
  2. 热米饭 + 酱汁（生抽/蚝油/糖/香油）拌匀
  3. 卧上温泉蛋和海苔碎，拌开即食

葱油拌面

  1. 小葱段小火熬到焦黄，倒生抽老抽白糖煮开
  2. 面条煮熟过一遍凉水更筋道
  3. 淋葱油酱汁拌匀，加个煎蛋更顶

实验报告《制取氧气》

化学实验
【目的】用高锰酸钾加热分解制取并收集氧气 【原理】2KMnO₄ →△ K₂MnO₄ + MnO₂ + O₂↑ 【器材】铁架台、酒精灯、试管、单孔塞、水槽、集气瓶 【步骤】查气密性 → 装药（管口塞棉花）→ 预热 → 固定加热 → 排水集气 → 先撤导管再熄灯 【结论】氧气助燃，用带火星木条检验复燃
